## Claims

- [fact] MCP is an open standard for secure, two-way connections between
  data sources and AI-powered tools, launched November 25, 2024.
- [fact] It replaces fragmented, bespoke per-tool integrations with a
  single protocol: developers expose data via MCP servers, and AI
  applications (MCP clients) connect to those servers.
- [fact] Anthropic released the protocol spec and SDKs on GitHub, plus an
  open-source repository of pre-built MCP servers for Google Drive, Slack,
  GitHub, Git, Postgres, and Puppeteer.
- [fact] Claude Desktop apps support local MCP servers at launch.
- [fact] Early adopters/partners named in the announcement: Block and
  Apollo (integration), and Zed, Replit, Codeium, and Sourcegraph
  (developer tools).
- [fact] MCP was released as open source under the MIT license (per prior
  research confirmed in earlier session searches — cross-check against
  the GitHub repo license file before stating on a slide).
